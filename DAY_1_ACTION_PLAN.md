## 🆘 TROUBLESHOOTING

### "0 signups after 4 hours"

**Do this**:
1. Test signup flow yourself (new email)
2. Ask 2 friends to try and screen share
3. Check error logs
4. Post in group: "Just launched, would love feedback on signup flow"

---

### "Signups but 0 campaigns"

**Do this**:
1. Email all signups: "Hey! Noticed you signed up. Any issues with campaign generation?"
2. Offer to help 1-on-1 (Zoom/Meet)
3. Check if onboarding is clear

---

### "Campaign generated but looks bad"

**Do this**:
1. Ask user: "What specifically didn't match expectations?"
2. Regenerate manually with better prompt
3. Note the issue for iteration
4. Offer extra credits as apology

---

### "Stripe not working"

**Do this**:
1. Check Stripe Dashboard for errors
2. Test checkout yourself
3. Verify all price IDs in .env
4. Check if webhook endpoint is needed (shouldn't be for Phase 4)
